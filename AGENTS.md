# Metro

## Docs

Docs are in `docs/`. Read them to understand Metro's intended behavior. If a change affects behavior they describe, update them in the same change; when reviewing, flag changes that make them inaccurate.

## Benchmarking

Measure performance-sensitive changes, and include benchmarks in PRs and reviews where relevant. See `scripts/benchmark-patches/benchmark-patches.js` (`--help`) for preconfigured benchmark setups.
